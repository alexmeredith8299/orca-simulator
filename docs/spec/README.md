# EXPAND.3 Phase I specification

Alex will add the spec PDF to this folder. It is the source of truth for `params/*.yaml`,
and model docstrings cite its sections (for example "Spec: Electrical power, battery model").

`EXPAND3_Extended_Faults_Supplement.md` is a supplement to the spec. It describes the navigation
filter, the magnetometer, the crosslink signal-strength reading and the six extended faults
(`gnss_jump`, `gnss_noise`, `tx_fade`, `mag_bias`, `mag_noise`, `mag_coupling`). The spec does not
cover any of them.
